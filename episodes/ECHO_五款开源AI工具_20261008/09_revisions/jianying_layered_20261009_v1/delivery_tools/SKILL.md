# 剪映分层导出：按大框独立编辑

把已完成的视频及源工程转成便于修改的剪映草稿。沿用当前项目内容与效果，只改变剪映交付结构。适用于 HTML/SVG、Remotion、AE 或其他可抽取图层的源工程；具体渲染适配依项目实现。

## 范围与输入

- 仅手动调用：用户明确写出 `$jianying-layered-export` 或要求使用“剪映草稿分层导出”skill 时才应用本流程。只说“导出剪映草稿”或“导入剪映”不自动触发本 skill。以下默认分层规则只作用于明确调用本 skill 的任务，不成为其他项目的默认导出规则。
- 用户要求“导出剪映草稿”时完成可用草稿包；明确“直接导入剪映”时，在已有授权内继续注册新草稿，不再重复确认。不因仅制作视频而自动导入。
- 读取当前项目实际入口与已确认配置；有 `production_standard.json` 时按其指针和哈希加载。不得把此 skill 所源自项目的 SOP、风格、镜号或目录当作其他项目标准。
- 查清成片、源工程、时间轴、可编辑文字、原始音轨和素材所在位置。继承原画幅、帧率、时长、字幕模式、人物动作、配色及字体，不固定轨道数、卡片数或音效数量。
- 仅有压平 MP4 时无法恢复原始文字/图形图层。先检查已有工程与素材；缺失时说明可交付边界并请求必要源工程，不把一段完整 MP4 声称为完整分层。
- 原成片、制作规则、SOP、原始源码与用户编辑过的草稿保持原样。新建项目内导出修订目录和独立草稿；转换代码放该目录。旧草稿的手动修改需要另行迁移，不能暗示已经保留在新稿中。

## 默认分层规则

| 内容 | 草稿中的结构 |
|---|---|
| 动画镜头 | 默认保留现有人物动作与镜头运动，按镜头放独立视频片段；需要修改人物动作时另按任务处理 |
| 信息卡背景 | 一层；不同卡片及不重叠动画镜头可复用底层轨道 |
| 大框 | 每个大框一个独立片段，保留原颜色、边线、圆角和动效 |
| 文字 | 每个逻辑文本块一个连续的原生可编辑文字片段；无需为改一句话修改许多碎片 |
| 框内图形与动效 | 每个大框各自合成一层透明素材，包含完整运动过程与中间帧；相邻大框不得烘焙到同一素材 |
| 跨框关系 | 真正跨框的连线、移动对象和公共图形放公共层；只在一个框内的线仍归该框 |
| 配音、音效、配乐 | 按已有声音来源保留独立片段/声部，时间不重叠时复用轨道，避免重复混音或重复应用增益 |

“每段文字单独”指独立可编辑片段，不是全片每句话都永久占一条轨道。轨道按并发占用和前后遮挡复用；单卡内同时出现的独立文字不能相互覆盖。

每个框体、框内图形和该框的文字均标明 `镜号｜框名｜内容`。默认不自动编组，不制作跨框复合片段。想整框移动时，用户可按编辑索引多选该框的片段。必要的前景形变或前景框可额外拆层，但必须保留明确归属和原遮挡关系。

文字里的关键词、标题和说明保持原生文字。已有演示录屏里的软件界面文字属于录屏内容，不伪装成可编辑文本；在交付说明中分清两者。

## 执行路径

1. **确定导出边界**：记录基准文件哈希、时间轴、声音处理和允许变化范围。使用当前输入，自行解决可逆实现细节，不增加逐卡确认关卡。
2. **建立对象归属**：为每张卡建立稳定 panel ID，将每个图形对象和文本块唯一归入所属大框或公共层。根据语义与运动过程确定归属，不能简单按画面左右硬裁。未归属或多重归属先修复，不默默漏掉。
3. **抽层并建草稿**：实现本项目适配器，参照 [适配技术说明](references/adapter-notes.md)。去掉将改成原生文字的重复栅格文字；从每框分别渲染透明动态图形，保留原运动、遮罩和遮挡。文字优先用单片段关键帧，不为复制逐帧状态拆碎文字。若某项复杂文字效果无法等效，记录差异；会明显改变效果时先解决或取得该项取舍，不能把历史简化当作通用许可。
4. **检查独立性与保真**：执行下节检查，修复导出适配器。不要为了少几条轨道重新合并相邻大框，也不要把原制作规则改成迎合导出限制。
5. **交付或注册**：按用户需求交包或直接创建新草稿。使用 [交付与注册说明](references/delivery.md)。未实际打开剪映播放/导出，只能报告结构和离线检查通过。

## 验证与证据

- 用 [包结构契约](references/package-schema.md) 写 `manifest.json`。`scripts/validate_package.py --package 路径 --report 报告路径` 验证素材、时间、对象归属、文本独立性、分组和声音设置；它不能识别像素里是否偷偷烘焙了邻框，必须配合以下画面检查。
- 对每张卡选择运动中、到达后及遮挡变化的代表帧，解码最终交付 PNG/MOV 并重组，与源画面对照。检查 alpha、黑边、裁切、字体、时间与图层顺序；编码前截图不能替代编码后检查。
- **相邻框不联动**：对每个含图形的大框，选择内容可见的帧，单独隐藏其图形，确认本框确实变化且相邻框区域保持不变。至少在代表性的双框场景中另测移动和缩放（操作幅度不应让素材物理越入邻框）；公共连接层保持独立不随动。只有文字/框体的面板单独核查结构。使用最终草稿的位置、缩放、层级和最终资产做检查。
- 原生文字一处修改生效；没有重复栅格文字；文字、图形和大框不会因共用可变 material 或分组而串改。记录形变前景等合理例外。
- 核对声音源、偏移、时长、已烘焙处理与片段音量，不同时叠加已混合母轨和其拆分声部。针对实际保留的音轨检查同步与增益。
- 报告绑定草稿、素材清单和检查依赖的哈希。改变相关输出后仅重跑受影响检查；区分结构通过、编码后画面通过、剪映原生播放/导出通过，不能互相替代。

## 交付要点

提供可用草稿、所需媒体与字体、按大框编辑索引、可重渲源工程或其已交付位置，以及实际完成的核验。说明哪些是原生可编辑文本，哪些是可移动/替换的合成素材，内部图标和路径需要源工程重渲。

给出新草稿名及文件位置；注册后不把脚本或 ZIP 当作唯一成果。保留旧草稿并说明是否迁入用户手动修改。用户已说自行寻找草稿时，不操作剪映界面、不重启编辑器，也不为主页是否立即显示反复检查。
