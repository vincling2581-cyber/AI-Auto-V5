# V5 v4.7 变更说明

2026-10-20，按用户本轮明确授权，将静态连环画与信息卡的边界落实到输入、声音、语义设计、分镜、插画、开头、卡片、样片、批量、合成、质检、交付和返工，并补充单图、同场景组与整语义段的共同规划。本轮仍为 v4.7，修订号由标准清单登记，不另建 v4.8。合并到主干后以主干 `CURRENT_PROJECT.json` 为准，旧版本保留；旧集锁定标准、素材和成片不自动迁移。不修改 V4，不修改全局 Skill。

| 调整项 | v4.7 执行方式 |
|---|---|
| 动画层定义 | 采用连环画式完整静态插画，单张显示期间人物、道具、图形和相机全部静止；只硬切，无推拉、平移、缩放、视差、局部形变、粒子、渐变动画、淡入、溶解等动效或动效转场 |
| 插画时长 | 单张连续显示 ≤2.0 秒，可以更短，无强制最短、固定间隔、目标时长或图片数配额。30 fps 时最多连续 60 帧；换字幕、改名、同图拆段或重编码不重置计时 |
| 长句承接 | 完整意思由有前后关系的多张图承接，不为上限修改原配音或切碎句意。每次切换须新增行动、条件、反应、结果、视角或关系理解，禁止随机补图、只改字和无意义微调凑时长 |
| 实际差异 | 场景、姿势、人物位置、道具状态或构图须体现有依据的变化；同时检查单图、同场景组和整语义段，强相关不能作为长期同场景依据。不要求每张全部变化，无场景固定时长、场景数、室外比例或图卡占比，也不规定换句必换景 |
| 跨情境连贯 | 可通过同一主角、目标、关键道具或因果串起实际受阻情境、行动、具体记录等不同情境，再用新的完整插画回到原场景表现新结果。换景必须有原文或明确合理示意依据，禁止回用旧图、随机换景或只换手势 |
| 信息卡层定义 | 专门组织命题、证据、比较、因果、映射、分支、流程等知识关系；允许连续语义动效与阅读保持，不受插画 2.0 秒上限限制。不能把普通情境图改名为卡片绕过要求 |
| 卡片过程 | 先命题和关系，再形式、对象与事件。保留对象身份、来源与结果、复制／转移区别、真实路径和中间帧、目标接收、前后遮挡及终态阅读，不以淡入、加字或高亮替代过程 |
| 角标与字幕 | 两层不添加固定品牌、栏目、集数角标、固定 badge。保留语义标题、步骤编号和必要正文；启用口播字幕时独立成层、固定底部居中，不随人物和主画面改变位置 |
| 画面质量 | 保留身份与笔触、所有可见睁眼的虹膜瞳孔、合理肢体归属和道具接触、自然满幅下沿及环境配色。明显动作通过不同静态插画的有意义状态变化表达 |
| 开头 | 先呈现与原文相符的问题、结果或反差和观看理由，不固定前 N 秒或镜数，不为钩子改词、变速、删停顿或编造承诺 |
| 样片与审片 | 分镜、出图、样片、整片审查均覆盖单图／同场景组／整段；样片验证计划内情境衔接和回场，未展示的不推定已认可。当前 5 图约 8.37 秒 demo 仅是试排，未获用户满意或全片正常速度视听通过 |
| 执行合同 | 标准 `production_standard/layer_contract.json` 对应本集 `03_storyboard/production_contract.json`；片段记录层、资产、帧区间、语义增量、声音锚点、变化维度及 motion／transition／corner_labels。插画逐图填写 `scene_id`、`scene_progress`，换景时 `scene_change_reason` 非空；scene_id 表示物理或叙事情境，不是图片 ID |
| 实现一致性 | 渲染实际消费本集 effective defaults；不允许只改规则却继续沿用插画内部运动、旧无上限、固定 2 秒切换或固定角标。卡片无上限字段不得回退成插画上限 |
| 机器与视听 | `validate_episode.py` 检查结构、时间和声明，汇总同场景连续区间，不能判断实际枯燥程度、审美或语义正确，也不据汇总设置场景时长／数量硬线。机器、原图／抽帧、正常速度整片主观视听、用户认可、剪映原生打开及导出分别记录；未执行不能写通过 |
| 工程与特别格式 | 默认成片与 HTML/SVG/JavaScript 可重渲源码，经浏览器和 FFmpeg 合成，无需 AE。剪映分层导出、注册、导入或 AE 仅按明确另提；剪映导出后复检由用户另提，转换约束不倒灌视频设计 |

SOP 保留 §0–13 及既有工作流引用所需的细分节号，全文改写为一致流程，清除旧版“插画可无限保持”“图内明显动作”“固定集数角标”等冲突要求。规则、提示词、默认参数、项目入口和阶段路由按同一边界同步；新版本不是新增任意 SRT 一键制作器。

保留原始声音、事实与来源、确定程度、五列分镜、单集独立目录、素材去重、对象追踪、卡片中间过程、正常速度阅读、可回退修改和依赖指纹。新集复制本版快照和锁形成自己的 effective defaults；旧集继续本集原锁，只有用户明确迁移时另行处理。历史完整生成器不作为新集入口；适配旧实现时检查实际字段消费和产出，不能仅凭参数已经改名认定适配完成。

本次标准更新的检查范围为文档、规则、配置、合同校验器及入口的一致性和结构验证，具体结果以实际报告为准。没有因此制作、重渲或重新验收一条新成片。正常速度整片视听须对应准确导出；缺少实际观看或试听能力时记录未执行和缺口，不以机器通过、抽帧、播放命令成功或局部样片代替“观感通过”。
