# 源工程到剪映的适配要点

在为当前项目编写导出适配器时读取。这里记录经本机源码核对的接口与分层方法；它不是可直接运行的通用渲染器，也不承诺其他剪映或库版本具有相同行为。镜头、帧率、尺寸、字体、动效时间和轨道数从当前项目读取。

默认导出分层草稿并注册为本机新草稿，同时提供带双击导入入口的便携 ZIP；明确只导出时跳过注册。本文件涉及的原生校准、画面对照、解码复合、隐藏/移动/缩放、试听及独立包复验，只在用户明确提出对应复检后执行。构建与注册自身的结构、路径、素材和索引约束仍需遵守，不能把已知转换错误当作“未复检”的正常结果。

## 先识别源与运行时

- 找到能重现成片的工程、时间轴、画面合成代码、文本数据、原始音轨与处理记录。只有扁平成片时，不能据此承诺恢复原生文字和完整分层。
- 在项目环境、已配置工具路径和 `PATH` 中寻找 Python、FFmpeg/ffprobe；用 `Get-Command`、`python -m pip show pyJianYingDraft`、`importlib.util.find_spec()` 等确认，记录实际解释器和模块位置。
- 用 `inspect.signature()` 核对当前库的构造函数、轨道、关键帧和注册接口；第三方示例不能覆盖本机接口证据。缺少所需能力时可交付已完成的素材、源工程或可用草稿包，明确剩余缺项，不假称草稿已完成或已安装。
- 默认注册时从当前剪映配置、已有索引或用户给定路径确认安装目录、用户数据目录、草稿存储目录；三者可能不在同一盘。明确只导出时不读取用户草稿索引；原生操作仍需用户另外提出。不要写死历史机器的盘符、用户名、安装版本或虚拟环境。
- 为本次导出建立独立适配目录。适配代码只读取源工程；不要把某集固定台词、素材、尺寸、镜号、色板或时间写进跨项目默认值。

## 动画层：插画、文字与底板独立

先识别动画镜头里的干净插画、标题/说明/标签及对应底纹/底框，区分场景自带的纸张纹理和环境背景。每幅插画/镜头、每个文本块、每个独立底板使用不同编辑单元与素材，分别建立片段。底板上的填充/纹理/描边若原本是一个对象，可作为一个底板；原本分别可调的对象不额外合并。没有文字或底板的镜头不创建占位层。

- 从源合成中关闭文字及对应底板输出干净插画；单独抽出底板，文字转成原生可编辑片段。插画原有的场景内容保持完整，不能用矩形裁图把字连同附近场景裁走。
- 已画进 PNG/JPG 或压平视频的字和底板不能直接抽成原始图层。优先寻找源图层、无字素材或可关闭叠加对象的渲染代码；需要恢复干净底图时只制作导出副本，保留原文件。没有可靠底图/文字内容时记录具体缺项，不能以复制整图、叠新字或删除文字映射冒充完整拆分。
- 插画保持源项目画面规则；静态图仍静态，已有合法动作按源保留，不因分层新增推拉、渐变或其他动效。底板按实际变化输出透明 PNG/视频，沿用下文固定裁剪坐标；多图共用一段说明/底板时，文字与底板可连续覆盖这些图，不强制跟每次切图拆碎。
- 保留各对象原位置、显隐、遮挡及共同父级变换；通常是插画下、底板中、文字上，实际前景遮挡仍按源顺序处理。不得把动画层标题/标签错误归为固定底中口播字幕。底板输出不得含重复文字，插画不得残留已经拆出的字或底板。
- 原生文字、底板及插画均可独立选择，不自动编组或装入不可独立编辑的复合片段。前后镜头可复用轨道，同时出现的对象需放在支持正确叠放的不同轨道，不能因共用可变素材而串改。文字的逻辑 ID、底板 ID、源对象与关联关系写入编辑索引。
- 简单底板也只有在当前工具实际支持独立原生形状时才承诺原生改色/改圆角。透明图形素材可单独移动、缩放、替换，其内部纹理与路径需回源工程重渲。抽层转换不自动授权原生校准或复检。

清单继续使用 schemaVersion 1。为插画、文字、底板分别注册 `panels` owner；干净插画用 `animation`，原生文字用 `text`，独立底板用 `graphics` 并在 `sources` 中列出真实底板对象。`animation` 和 `text` 不填写仅属于图形角色的 `sourceObjectIds`。`layeringMode: "card_text_split"` 只描述信息卡结构，不要求将动画层的文字底板并入插画。表示示例见 [包结构中的动画层映射](package-schema.md#illustration-text-and-plate-mapping)。

## 默认信息卡模式：文字独立，非文字合成一层

每张卡建立稳定 scene ID；默认只有一个非文字导出编辑单元 `card_visual`，每个逻辑文本块独立。将标题、标签、数字等源工程可编辑文字从画面渲染中剔除后，该卡背景、所有框体、图标、插图、箭头、跨框连线及其他非文字动效一起按源绘制顺序渲染。保持完整运动过程，不能用状态截图替代。口播字幕、字幕底板及音轨独立处理，不属于该卡的非文字合成。

沿用现有清单契约即可，不需新建原生草稿格式。`panels` 在此表示导出编辑单元；`sources` 是该单元负责导出的全部非文字对象，包含背景与框体。简化示例（实际包还需媒体、原生草稿及每个片段的完整映射）：

```json
{
  "layeringMode": "card_text_split",
  "panels": [{"scene": "C01", "id": "card_visual", "label": "信息卡非文字合成"}],
  "sources": [{"scene": "C01", "objects": [
    {"id": "background", "owner": "card_visual"},
    {"id": "left_frame", "owner": "card_visual"},
    {"id": "right_frame", "owner": "card_visual"},
    {"id": "cross_card_route", "owner": "card_visual"}
  ]}],
  "segments": [
    {"id": "card_visual_segment", "scene": "C01", "role": "graphics", "owner": "card_visual", "sourceObjectIds": ["background", "left_frame", "right_frame", "cross_card_route"]},
    {"id": "title_segment", "scene": "C01", "role": "text", "owner": "card_visual", "textKey": "title"}
  ]
}
```

- 每张卡输出一个连续非文字画面片段；前后不同卡片可以复用轨道，不能将全片卡片合成单个不可逐卡替换的视频。静态用图片，动态用视频；含不透明整幅背景时不必强用透明 MOV，叠加在其他画面上的卡片则保留 alpha。保留原画幅、帧率、时长、配色和动效。
- 源对象 ID 跨帧稳定；动态创建、隐藏、进出画幅的对象均列入全集，每个对象在该场景恰好由一个片段负责。旧大框的语义归属可写入索引供追溯，但不要据此又拆成多个交付层。不得用 `shared_graphics` 冒充整卡合层；本模式用明确的 `card_visual` 所有者及 `graphics` 角色。
- 原生文字独立保留移动、缩放、入退场及与非文字对象的时序关系。不要将卡内正常文字动效套用口播字幕的固定定位规则，也不要把可编辑文字残留在非文字素材中。录屏或嵌入图片里本来就无法独立提取的界面字属于原始媒体内容，须说明编辑边界，不能承诺可改字。
- 合层后通常将非文字素材放在文字下方，但须先识别原有遮挡关系。前景图形若会挡住原生文字，优先采用当前已支持的文字裁剪、遮罩或显隐保留效果。部分遮挡不能简单把整段文字隐藏；能力不足时说明该对象的冲突并按用户已定取舍处理，不能默默多拆非文字层、压平文字或把应遮挡的字提到前景。
- 源中对“图形+文字”整体应用的 opacity、mask、filter 需要在抽层时处理组合语义，不直接逐层复制导致双重 alpha 或穿叠变化。构建时遵守已知能力限制；原生视觉复检仍只在用户提出后执行。

## 可选模式：按大框拆分

仅在用户明确要求大框或图形对象可独立编辑时使用，记录 `layeringMode: "panel_split"`。以下约束不适用于默认整卡非文字合层。每个大框、每个文字及图形对象都有稳定 ID。示例：

```json
{
  "panels": [
    {"owner": "panel_left", "graphic_ids": ["demo_video"], "text_ids": ["left_title"]},
    {"owner": "panel_right", "graphic_ids": ["flow_icon", "internal_arrow"], "text_ids": ["right_title"]}
  ],
  "shared_graphic_ids": ["between_panels_route", "travelling_packet"],
  "shared_text_ids": ["card_heading"]
}
```

- 大框、框内图形、框内文字分别保留归属；框内图形可合并成该框自己的连续透明素材。相邻框不能共用一个含双方内容的图形素材，也不添加跨框联动组。
- 真正跨框的连线、传递包、公共标记单独归入共享层；一个框内部的连线仍属于该框。归属不能仅由对象某一帧的左右坐标决定。
- 动态创建、暂时隐藏、进出画幅的对象需要跨帧稳定 ID。扫描完整有效时段，收集源对象全集；每个对象恰有一个归属，未知、漏掉或重复归属立即报错。
- SVG 可复制原对象及必要祖先的 transform、clip、mask、filter、defs，移除其他语义对象，并嵌入引用图片。保留内部对象组合关系；不要按画面左右矩形硬裁源截图来冒充语义拆分。
- 文字从图形输出中剔除后再建原生文字。大框填充/边线也独立导出；已有小框属于哪个可编辑单元，按实际内容和用户要求决定。
- 嵌套大框、前景形变、遮挡结果框可能需要额外前景层；按源渲染顺序保留，不为凑“一框一层”破坏遮挡。
- 移动胶囊、标签、包裹等含原生文字的对象，保留源中“对象背景/图形/文字”相互交错的实际绘制顺序。发生穿叠时，后方对象的文字也应被前景对象覆盖；不能将所有原生文字统一提到全部图形之上。需要的前景遮挡层仍保留所属对象，且每段文字继续独立可编辑。用户要求遮挡复检时，对穿叠过程及分离后的状态分别核对。
- 如果原来对“框+图形”整体施加 group opacity，拆开后逐层 alpha 合成可能改变视觉。读取实际背景和组结构分析合成，不直接照搬别集的颜色补偿；关键过程帧验证留到用户明确要求复检时。

## 连续画面素材与裁剪坐标

动画层对独立文字底板应用下列规则；默认信息卡模式对每张卡的非文字合成应用，按大框拆分模式对每个拆出的单元分别应用。全画幅不透明卡片可直接用固定画布视频；需要透明叠加或裁剪时按下面的 alpha 范围处理。

1. 按源帧率逐帧采样过程动画，保留移动、绘制、形变、归档的中间帧。不要改成几张状态截图与入退场。
2. 对某层所有有效帧的 alpha 包围盒求并集，加适合该层阴影、滤镜和编码的边距。所有帧使用同一个裁剪矩形，防止动作过程中素材中心漂移。需要偶数尺寸的编码器应扩充透明边缘。
   SVG 的几何包围盒宽或高为零，不代表对象不可见：水平/竖直描边线、端点及 marker 仍可能有可见像素。筛选和裁剪要计入 stroke、端帽、连接、marker 与变换后的范围，或以实际渲染 alpha 为依据；不得因几何 `width == 0` 或 `height == 0` 直接丢弃分隔线、连接线等对象。
3. 记录裁剪左上角 `(crop_x, crop_y)`、宽高 `(w, h)`、画布中的中心 `(crop_x+w/2, crop_y+h/2)`，以及源开始/结束帧。内部完全隐藏区间保留透明帧，不能跳帧压缩时间。
4. 帧像素完全相同可用透明 PNG；存在变化则输出带 alpha 的连续视频。已用过的路径是 ProRes 4444 MOV（`prores_ks`、profile 4、`yuva444p10le`、alpha 16）；沿用可用编码配置，未确认的当前剪映兼容性如实记录，不自动新建原生测试。
5. 给每个语义资产独立路径、material ID 和 segment ID，保留源对象 ID 列表及哈希。轨道可复用，独立编辑单元不能因复用轨道而合并。
6. 仅在用户要求编码画面复检时，解码最终 PNG/MOV 后按记录的中心和实际渲染顺序复合，再与源画面对比。仅查看编码前 PNG 无法发现编码丢 alpha、黑边、尺寸或首尾帧错误。

用户要求原生遮罩复检时，在剪映原生过程帧中验收遮罩和透明边缘。源中没有可见轮廓的遮罩，不得因默认 stroke 或半透明边缘产生空矩形、细线或黑边；复检覆盖遮挡开始前、穿过内容时及隐藏后。编码后离线复合通过，仍不能替代这一原生检查。

用于隐藏原生文字的前景遮罩只应遮挡目标内容。安排其范围、时段和绘制顺序时，考虑无关移动对象是否会经过该区域；不能因遮罩层级过高切掉经过对象的背景、文字或连线。用户要求相应原生复检时，除灰边和空框外，还应对照早期进入、穿越中途及离开后的原生帧。

可复用的编码命令形状（变量来自本集；输入应含全部连续帧）：

```text
ffmpeg -framerate FPS -i frame_%06d.png -an -c:v prores_ks -profile:v 4 -pix_fmt yuva444p10le -alpha_bits 16 panel_graphics.mov
```

## 原生文字：按逻辑内容和实际出现时段编辑

- 先区分口播字幕及其底板与信息卡文字：前者按 [固定定位规则](text-motion.md#口播字幕的固定定位) 默认放在底部中央，处理源位置状态时即应用；后者继续保留源动效。字幕 Alpha 恒为 1 也不能跳过位置处理。
- 默认同一连续出现区间用一个原生 `TextSegment`。首尾隐藏区间裁到实际起止，中间消失再出现按已支持的显隐能力处理；必要的少量出现片段共享逻辑索引但不共享可变 material，不承诺修改一个独立片段就同步全部。不要为“一段到底”引入零缩放隐藏，也不要按每帧颜色/透明度碎片化。实际映射遵循 [text-motion.md](text-motion.md)，可复用 `scripts/text_motion.py` 的纯函数。
- 文字对象应在源层显式标注归属。若源无归属，可用稳定可见时段的完整文字中心与最小包含大框辅助判定；有跨框、重叠或移动的文字必须语义复核，不能以瞬时遮罩边界归属。
- 从 SVG 提取文字时，以实际渲染的空白行为为准。原始 `textContent` 中连续的 ASCII 空格、制表符与换行，可能已被源渲染器折叠；直接复制到剪映会改变字距、文本宽度和对齐。依据有效的 `white-space` / `xml:space` 处理普通折叠模式，同时保留明确要求的空白、非断行空格及 `tspan` 的定位语义；不要对所有文本一律删空格。用于原生内容、样式区间、测量及索引的文本应采用同一结果，并与源画面核对。
- 记录源字体文件、字重、字号、字距、行距、对齐、文字框/字形坐标基准。SVG 字体盒中心不一定等于剪映原生文字中心；导出时沿用适用的已有映射，并记录其适用范围及未确认项，不自动新增校准。
- 用户明确要求校准时，样例须在当前剪映原生预览或原生导出中实际采样，包含所需字体、字重、大小范围与对齐/换行情形。不得将某个倍率当作通用正确值，也不得用草稿字号逆换算后在 SVG/PIL 中重画来自证。按 [native-evidence.md](native-evidence.md) 保存证据；修改映射、草稿、媒体或字体后使相关旧证据失效，但不会自动授权重做复检。
- 本机已核对的 `TextSegment(..., font_path=...)` 只保证写入顶层字体字段；保存后还需检查 `materials.texts[].content` 中各 `styles[].font.path`，粗体样式使用实际粗体字体文件并保留 `bold` 标记。
- 使用包内字体时，除顶层 `font_path`，还要处理 `content` 这种 JSON 字符串中嵌套的路径。只有许可允许时才分发字体。系统字体模式留空文件路径，记录 `fontDependencies` 的名称、字重及环境要求，不把本机绝对路径伪装成可移植引用。仅有字体名称不能保证换机字形相同，也不能满足当前完整原生证据中的文件绑定；不要为通过门禁复制无权分发的字体。
- 透明度存在多个载体：segment clip alpha、material global_alpha、`styles[].fill.content.solid.alpha`。不要重复乘入同一源透明度；静态不透明文字应检查最终有效值，而不只看一个字段。
- 当前核对的公开上游将 `KFTypeAlpha` 限定为视频能力，文字有同名可写字段并不证明支持。没有对应原生证据时，不直接给文字写视频 Alpha 曲线；使用适用的原生文字动画或明确处理能力缺口，详见 [一手来源](compatibility-sources.md)。旧“alpha 为零就把 scale 设零”方案不再作为显隐推荐。
- 效果近似必须具体说明。已有支持范围内的普通入退场不应任意降级；透视/剪切/复杂遮罩无法保留时，按用户已定的可编辑性和保真优先级选择，否则明确询问该项取舍。效果保真素材与可改字文字若同时保留，必须有清楚的切换方式，不能两套一起显示。

## 已核对的 pyJianYingDraft 接口形状

下例在本机所用分支与本次核对的公开上游中使用 `append_track/TrackSpec`；其他版本先检查签名，不把旧 `add_track` 示例原样套用。`font_path`、`content_codec`、`user_data_path` 是需另行核对的分支扩展，不能通过安装同名 PyPI 包假定存在。精确来源见 [能力对照](compatibility-sources.md)。

```python
import pyJianYingDraft as d
script = d.ScriptFile(canvas_width, canvas_height, fps, False)
lane = script.append_track(d.TrackSpec(d.TrackType.video, name="信息卡｜非文字合成"))
segment = d.VideoSegment(material, d.Timerange(start_us, duration_us),
                         volume=0, clip_settings=settings)
script.add_segment(segment, lane)
segment.add_keyframe(d.KeyframeProperty.position_x, offset_us, normalized_x)
payload_json = script.dumps()
```

- 时间单位是微秒：`T(frame)=round(frame*1_000_000/fps)`。半开帧区间 `[a,b)` 对应 `Timerange(T(a), T(b)-T(a))`；不要分别累计已舍入的单帧时长。关键帧时间是片段内偏移 `T(f)-T(a)`，更新片段起点后必须重算；不得把全片时间直接写入局部偏移。
- 对宽高为 `W,H` 的画布，本机坐标换算为 `transform_x=2*x/W-1`、`transform_y=1-2*y/H`；源图像坐标 Y 向下，草稿 Y 向上。旋转、锚点是否经过原生验证须如实记录。
- 本机剪映会先把素材按比例适配画布。若裁剪素材需保持源像素大小，其缩放补偿是 `1/min(W/w,H/h)`，再乘源 scale；换其他素材适配模式或版本后记录兼容性未确认，用户要求复检时再检查。
- 已核对的 `dumps()` 按 `track_order` 排序，为每条轨道的片段写 `render_index`，不是所有 video 固定在 text 下方。创建轨道时遵循源遮挡关系，之后检查实际 JSON 的 render_index；只核对轨道名不够。
- 按角色与遮挡兼容性复用没有时间重叠的轨道，文字每段保留独立片段；不要把轨道数量设成某集固定值。默认模式每卡只有一个非文字编辑单元；只有用户选择按大框拆分时，同时可见的大框内容才各自独立。

## 音频与时间轴

- 角色动画沿用源镜头视频时，保留原动作和源时长；已有画面素材中的声音按原混音方案处理，避免叠出第二份配音。
- 分开保留配音、音效及已有音乐的可编辑片段。源音效表以 sample 为单位时，按其真实采样率换算微秒，不能先取整到视频帧。
- 记录每项增益是在文件中已烘焙还是由草稿应用。已处理的声音源通常草稿 `volume=1`；未经处理的文件再按原混音参数应用一次。不要同时导入完整混音和其所有组成声轨重复播放。
- 若音效时间重叠，增加必要轨道；可顺序共轨的片段复用。不要继承旧集音效数量、名称、固定增益或事件时点。

## 可移植包与本机注册

- 可移植包内媒体用相对路径，含文字字体嵌套引用；记录草稿、素材、源对象归属、轨道/文字索引与 SHA-256。写完说明后打包；ZIP CRC 与条目哈希复验仅在用户明确提出时执行。
- 默认新建独立草稿目录和新 ID 完成本机注册，同时交付便携 ZIP，不覆盖原草稿，也不默认迁移其中手动修改。用户明确只要草稿文件/压缩包时，跳过注册，生成完成即交付。均标注“复检未执行”，不运行原生证据门禁。安装助手与双击导入入口的要求见 [delivery.md](delivery.md)，不能因缺证据自动展开校准。
- 本机所用分支扩展提供 `DraftFolder(..., content_codec=..., user_data_path=...)`；公开上游的构造参数不同。原生加密支持依赖当前分支、平台和本机剪映组件。区分新建、读原生保存文件、同格式写回、注册和 UI 导出，不用“某大版本以上全部加密/不支持”概括。现场核对类、签名和文件内容，不手写猜测加密结构；JSON 解析失败也不能单独证明加密。
- 先查重、验证包内全部媒体，再复制。注册时将 `media/` 以及嵌套字体路径递归映射到新目录，核对新名字、ID、时间轴和媒体可读性。
- 修改根索引前备份，复制素材后再次确认索引未变化；变化时读取最新状态再处理，不能覆盖用户刚保存的索引。注册后只新增目标条目，并检查原条目与既有草稿未被本次安装改变。
- 单次注册失败后先定位失败阶段，避免无限重试或反复创建同名垃圾草稿。发现编辑器并发改索引时停止该次注册，保留已完成的可移植包；不擅自关闭、重启或操作用户编辑器。
- 验证分三层陈述：离线结构与素材复合；本机文件/索引注册；剪映实际播放或导出。前两者成功不代表第三者通过。
- 用户已选择按大框拆分并要求“相邻大框联动”复检时，用最终包的真实素材和变换分别隐藏、平移、缩放一个框的图形，检查邻框区域不随之变化。先排除测试故意移动到邻框造成的遮挡；跨框共享连接单独测试。默认合层模式的各框随素材一起移动属于预期，不运行此项。

适配完成后保留明确局限：PNG/MOV 可移动、缩放、替换和裁剪；其内部图标路径并不会自动变成剪映原生矢量控件。文字只有实际保留为原生文字时才可直接改字。
