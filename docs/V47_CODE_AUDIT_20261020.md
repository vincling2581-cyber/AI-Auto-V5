旧 TEST 的 `06_project/app.js` 固定 30 fps、1678 帧和角标。只读 Node VM 复现：将有效配置改为 60 fps、关闭角标，第 300 帧仍返回 10 秒，仍出现 `ECHO / HUMAN 3.0`，第 2000 帧仍被拒绝。旧 `cards.js` 固定部分配色，旧 `index.html` 固定画布。五工具旧集的初始化脚本还读取 V4 来源和当时输入路径。这些是旧集实现事实，不能通过复制并修改 JSON 就当作新集适配完成。

上述代码继续服务旧集重渲，保持原样。新集复用时要在新集内适配并测试参数消费，不能把本次新增入口当作旧渲染器已经自动改造。

修复前发现 8 组完全相同源码，主要为试验、标准快照、旧集修订及便携交付副本。典型包括 9 份 `card_kit.js`、3 份试验 `render_cards.py`、原集与交付的卡片场景副本、TEST 修订脚本，以及旧标准检查器副本。便携导出中的两份同名校验器也各有调用者，删除会破坏原交付。

因此保留 `00_brief/standard_snapshot`、旧集 `06_project`、修订 `source/source_render/source_build/delivery_tools/adapter` 和清单锁定的源码。没有足够证据把这些文件标为可删除废弃代码；本轮不按重复率批量删除。未跟踪的三个旧集目录没有纳入内容审查，也没有删除或上传。
