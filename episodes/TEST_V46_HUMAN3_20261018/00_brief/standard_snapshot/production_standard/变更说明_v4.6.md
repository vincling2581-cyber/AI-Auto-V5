# V5 v4.6 变更说明

2026-10-18，用户明确确认规则调整方案，并授权更新 V5 的 SOP、规则、提示词和默认参数。只作用于当前 V5 工作区的新标准；旧集标准锁、素材、成片和其他版本保持原样。

| 调整项 | v4.6 的执行方式 |
|---|---|
| 节奏 | 取消同状态 3 秒上限、2.8 秒目标及固定切图间隔；按完整语义、配音锚点、动作完成和阅读需求安排。没有替代的秒数上下限或每分钟换图配额 |
| 保持与切换 | 完整 3 秒句子可以一图；同场景可以跨字幕。出现新对象、行动、条件、转折、结果或焦点时才考虑变化；长保持检查表达作用，不因超时自动切图 |
| 插画场景 | 参考《闲鱼暗号》，先根据文案选情境，再安排地点、机位、景别、主体尺度及动作；连续动作维持必要连续性，全片不固定室内工作台 |
| 配色 | 保留角色绿与奶油纸感，场景采用自然颜色及暖冷光；卡片提供浅纸色和深色起点，也可登记题材色板。浅色为通用 fallback，各场景仍按语义选择，局部文字/线条对比同步检查 |
| 信息卡 | 结合《闲鱼暗号》的证据、映射、循环、引用、对照和极简结论，与《Skill工作手册》的对象连续、展开、转移、归档、调用及分发。先关系后版式，允许无框；绿白配色仅用于已经选中的双框形式 |
| 语义与重复 | 核对原文主体、行动和关系；遮去标签检查画面是否仍表达关键含义，准确术语/证据文字按需保留。比较场景、构图、光色及卡片形式的重复，不以随机手势、数量积木、换字换色代替含义 |
| 质量要求 | 保留人物身份、虹膜瞳孔、合理肢体与道具接触、有意义的动作、完整下沿、事实和声音检查、卡片中间态与阅读保持 |
| 流程 | 五列分镜、分阶段读取、成片与可重渲源工程交付沿用。剪映分层导出只按明确要求，默认导出即停止，复检由用户另行提出 |

不设室外比例、场景数量、动作镜头比例、插画/卡片占比或必须使用多少种卡片的配额。相同语义自然需要重复时允许保持结构，不能为了“多样化”破坏理解。

同步更新的入口为项目根 `AGENTS.md`、`CURRENT_PROJECT.json`、`docs/SINGLE_EPISODE_WORKFLOW.md` 与 `README.md`。有效标准在 `standards/v4.6/`，包含本版 SOP、规范 JSON 及由 JSON 对应生成的规则/提示词 Markdown、参考来源、通用绘图组件和标准锁。

新集复制本版标准并形成自己的 `effective_defaults.json`；旧集继续锁定原版本。旧生成器可能含固定秒数/帧数断言，不作为新集入口直接运行，适配复用时必须移除这些限制；无上限字段的 `null` 不能被旧逻辑回退成 3、2.8、2 或 0 秒。帧率、声音对轴、总片长和编码检查仍然有效。新版本没有新增一键视频生成器。

本次检查范围为标准文件、配置一致性、入口及哈希锁，未重渲或复检已有成片。新规则的实际视觉效果由下一集实际制作验证，不能把配置检查称为成片验收。

本地品牌参考图片从 V5 已有资产复制并核对原哈希，仍按现有仓库政策留在本地。换机后按 `brand_assets.json` 恢复；标准校验会明确报告缺失，不能删除锁条目冒充完整。
