# 静态连环画节奏演示

主演示为 `exports/demo.mp4`，原三图对照为 `exports/baseline.mp4`。两份均为 1920×1080、30 fps、251 帧、8.366667 秒，取原片全局第 `[947,1198)` 帧，即 31.566667–39.933333 秒。

主演示依次保持 55、54、46、53、43 帧，对应 1.833333、1.800000、1.533333、1.766667、1.433333 秒。每张完整保持为静态图，图间硬切；只有适配输出尺寸的一次性缩放，没有推拉、溶解、角标、图解或信息卡。对照版按旧版实际图段，依次保持 70、85、96 帧，即旧版全局 `[947,1017)`、`[1017,1102)`、`[1102,1198)`。

字幕保留原 SRT 第 18–22 条的文字和可见帧，固定底部中央，微软雅黑粗体 44px，白字深色描边，没有字幕动效。第 23 条与裁切末端仅重叠 0.333ms，且不覆盖任何实际视频帧，因此未纳入。

音频来自 `00_brief/input/10月18日.mp3`，按原 44.1kHz 精确裁取每声道 `[1392090,1761060)` 样本，共 368970 样本。仅裁切并重设时间戳，未变速、重采样、调增益或添加声音。主演示最终封装时进行一次 320kbps AAC 编码；对照版直接复制主演示的 AAC 数据包，没有再次转码。有损编码后的 RMS 相对原音片段约为 -0.0544dB，记录该差异，未用增益处理补偿。

重渲染两份视频并运行机器检查：

```powershell
python .\render_demo.py --baseline
```

只准备素材和字幕可使用 `--prepare`；检查现有主演示可使用 `--check`。需要 Python、NumPy、Pillow，以及 `D:\ffmpeg\bin\ffmpeg.exe`、`ffprobe.exe`。脚本只在本演示目录内写文件。

机器检查结果在 `qa/check_results.json` 与 `qa/baseline_check_results.json`；逐条命令在 `qa/commands.json`，FFmpeg 日志也在 `qa`。主演示检查覆盖视频帧数、分辨率、帧率、段长、硬切边界、排除底部字幕后的主体区域静态程度，以及完整音视频解码、原音样本数量、首中尾对齐和漂移。对照版已完整解码，且 AAC 数据包哈希与主演示一致。

正常速度主观视听未执行，原生剪辑器打开和导出未执行。本测试不修改全局标准、旧成片或本集状态。
