# 本目录的视频制作入口

开始或恢复本目录的视频工作，先读取 `production_standard.json`，再读取它指向的完整 SOP、统一提示词、默认参数与本集标准锁。不要按文件名、修改时间、旧目录或历史记忆猜测当前标准。标准加载器会核对入口所列哈希；缺文件或内容漂移须先同步记录，不跳过检查。

当前统一版本是 v4.5，已按用户2026-10-06“你自己再检查一次，没有问题就可以”的明确授权，自检通过后启用。授权方式为 delegated_self_check，不表示用户亲自逐条审阅。自检结论由入口的 `self_check` 指向，不再要求用户逐项确认标准。已有明确要求继续有效；默认参数是可按内容调整并记录的制作起点，用户本集最新明确要求优先，不让旧代码默认值隐式覆盖。

新集可运行 `python production_standard/start_episode.py --name 项目名` 建立独立输入与标准快照。此入口不自动生成视频，也不操作编辑器。旧集脚本含固定文案、镜号、时点和素材，不能直接作为新集内容。历史 SOP/提示词仅供追溯，历史构建器需显式历史复现。`build_standard.py` 只读取当前入口及规范 JSON 生成审阅文档、更新哈希，不回填旧 SOP 或旧参数。

三项制作约束不可遗漏：可见睁眼人物有虹膜和瞳孔；动画层同一语义内容状态连续不超过3秒（制作目标2.8秒）；解释型信息卡有实际连续运动过程及中间帧，不能仅用入退场/高亮或状态图拼接。动画层保持时长和卡片过程动效分开检查。

动画层保留有用的文字/图示动画，同时增加人物姿态、重心、手臂和互动道具明显变化的动作镜头。图片的台面、地面或环境自然延伸到画幅下沿，不预留横向空白字幕带、不把整幅场景缩小上移。字幕按本集配置叠在完整场景上并避开关键动作。动作参考视频的外框/字幕带不继承，下沿构图以用户841–843截图为准。不擅自禁用文字、删除字幕、设动作占比或强制人物连续骨骼动画。

按入口所指最新信息卡方法和有效参数制作；通用卡片工具不包含某集固定内容。卡片总结或补充文案，维护对象身份与关系，用路径移动、绘制、遮罩展开、形变、归档等过程解释内容，并检查到达、遮挡和阅读保持。两个并列大框优先深绿色、白色；三个及以上可用浅绿及其他颜色。一个大框配小框不强制改成并列配色。人物检查不能只数手掌，应核对肩→肘→腕→手、袖管分支、左右归属与道具接触。

音效按本集内容与授权启用，保留事件表、单条声音源及处理记录，同一增益不重复应用。样片音效数量、增益、固定镜号和修复姿势不成为新集固定值。局部修订记录允许变化范围与保留项；旧检查仅对相同依赖和输出证据有效。

用户审阅分镜采用“镜头号、对应文案、预估时长、画面类型、大概画面简介”五列，内部保留完整制作数据。已授权范围内自检推进，不增加逐图确认关卡。

默认交付成片和可重渲源工程，不创建或导入剪映草稿。只有用户后续明确提出需要导入剪映才单独操作；历史导入授权不延续为新集默认要求。剪映导入技术步骤不纳入本版 SOP、提示词和默认制作流程。当前任务仅更新标准，不改旧集素材、成片、标准锁或活动工程。

改标准时同步提示词、参数、来源、自检说明与哈希。本版后续直接用于制作；未来新增要求按其实际授权处理，不因本版自检启用而自动授权无关变更。旧验证结果只适用于对应文件、运行参数和版本。
