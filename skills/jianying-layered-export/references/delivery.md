# 草稿包与本机注册

本 skill 的助手脚本不负责把任意 MP4 自动还原成图层。通过当前项目渲染/抽层适配生成草稿包；默认继续注册本机新草稿，并提供带双击导入入口的便携 ZIP。明确只导出时跳过注册，明确只导入已有包时不重新制作视频。仅修订本 skill 不触发真实草稿导入。

注册包含安装前后必要的结构、路径、素材和索引检查；独立复检、原生校准、打开草稿、试听及剪映原生导出仍须用户另行提出。缺少原生证据不阻止普通导出/注册，复检状态另记 `not_performed`。本机导入由助手直接完成，不把解压 ZIP 和双击脚本留作用户在当前电脑上的必做步骤。

## 包与记录

按 [package-schema.md](package-schema.md) 生成包内相对路径清单，文本嵌套 JSON 中非空的字体路径也应指向包内文件。系统字体可使用明确的依赖声明并留空文件路径，不能承诺换机字形一致。建议结构：

```text
export-revision/
  package/
    draft_content.json
    manifest.json
    native-evidence.json   可选；用户要求原生验收并实际执行后保存
    evidence/              可选；仅存实际执行复检取得的证据
    media/                 必要图片、透明动效、镜头、声音、字体
    draft_cover.jpg        可选
  source/                  本次源工程与适配器，或记录已经交付的实际位置
  import_tools/            便携包所需安装助手及同版本依赖
  双击导入本机剪映.cmd      调用同目录的 PowerShell 导入入口
  导入本机剪映.ps1          发现/接收目标机参数，再调用安装助手
  信息卡与文字编辑索引.txt
  检查报告.json             仅记录实际完成的检查，不伪造原生通过
  编辑说明.txt
```

默认编辑索引列出镜号、卡名、片段名、轨道、起止时间及源对象 ID，区分“动画插画”“动画可编辑文字”“动画文字底板”“信息卡非文字合成”“信息卡可编辑文字”“口播字幕/底板”。动画层按插画、每个文字块及每个独立底板分别建立索引，记录文字与底板的关联、跨插画连续出现时段、原生/素材类型和已烧录内容的拆分局限。文字可直接改字；透明底板素材可单独移动、缩放、替换，内部纹理、颜色和路径的原生编辑能力按实际实现说明。

每张信息卡的所有非文字内容仍为一个片段，文字按逻辑块独立；前后卡片可共用轨道，片段名保留具体内容。非文字素材可整层调整与替换，内部框体、图标、线条等需回源工程重渲。不能声称这些元素可在剪映中分别修改，也不能把多张卡合成一个长片段。口播字幕和底板仍独立于信息卡并默认固定底部中央；动画层标题/标注与底板保留其原有语义定位。

仅在用户明确选择按大框拆分时，索引改按框名区分框体、文字、框内图形及跨框公共层。记录实际 `layeringMode`，不要拿旧导出器的多层结构冒充新的默认结构。无论哪种模式，PNG/MOV 内部都不会自动成为剪映原生矢量。

默认同时交付 ZIP，用户明确不需要压缩包时省略。先写完全部说明再打包，可在归档清单中记录字节数和 SHA-256。默认不追加 ZIP CRC 或逐项哈希复验；用户要求包完整性复检时才执行，并绑定最终归档。可重渲源代码不得依赖未交付的旧集修订目录。

## 便携 ZIP 与双击导入

每次实际导出时，由本次适配器按上面的交付结构生成 `双击导入本机剪映.cmd` 和配套 PowerShell 脚本。仓库安装助手可复用，但不自带 Python、剪映安装目录或草稿根的自动发现；不能把单个 `.cmd` 或填写作者电脑路径的脚本当作通用导入器。

- ZIP 包含 `package/`、必要媒体/字体、编辑说明、编辑索引和 `import_tools/` 中的 `install_draft.py`、`validate_package.py`、`native_evidence.py` 等实际依赖。源工程一并交付或明确其已交付位置；不引用本机未打包的旧集工具。注册审计与旧索引备份留在本机独立审计目录，不作为导入依赖打包。
- `.cmd` 正确引用自身所在目录并调用同目录 PowerShell 脚本；脚本以 `$PSScriptRoot` 定位包和工具，路径含中文或空格仍有效，不依赖调用时工作目录。包含中文的 Windows PowerShell 5 脚本使用 UTF-8 BOM；保留安装器退出码及明确错误提示，双击运行时让用户能读到结果。
- PowerShell 薄包装在目标机发现或接收实际 Python、剪映安装目录、User Data、草稿根参数。优先使用当前配置/已确认运行时，区分安装目录、用户数据和可自定义草稿存储位置；不复制作者机器的盘符、用户名、Python 环境或历史剪映版本。发现有歧义时列出待填参数，不猜测并写入错误草稿根。
- 先确认该 Python 具备安装助手所需的兼容分支接口；缺依赖时给出具体模块/能力错误，不自动安装软件、替换库或剪映组件。便携包包含草稿和助手，不保证任意电脑无需安装兼容环境；编辑说明写清实际依赖。
- 用户完整解压后双击入口，薄包装将包相对路径和目标机参数作为独立参数传给安装助手，使用普通未复检模式的 `--install`，生成唯一新草稿名与新审计目录。不使用字符串拼接或表达式求值执行含用户路径的命令，不添加原生证据门禁或测试标签，不覆盖同名旧稿。
- 安装器把媒体/字体复制到新草稿自身目录并重定位引用，不能把注册稿链接到 ZIP、解压临时目录或作者电脑。注册失败时保留包和明确结果，不循环建稿或自动重启剪映。已在当前电脑注册的稿无需再次双击导入；重复导入只新建独立草稿，不覆盖既有编辑。
- 报告真实的新稿名与安装目录，区分“文件/索引已注册”和“剪映首页实际显示”。不为证明首页出现自动打开/切换剪映窗口；需要界面确认由用户另行提出。

## 找到运行时

- 检查目标项目已有导出工具、当前 Python 环境、`Get-Command python,ffmpeg,ffprobe`，必要时查看用户已配置的虚拟环境。不要把任何历史机器的盘符、用户名、Python 环境和版本号写成要求。
- 构建草稿可以用目标环境实际支持的剪映库。附带安装助手需要分支扩展的 `DraftFolder(..., content_codec=..., user_data_path=...)`、`JianyingDraftCryptoCodec` 与 `DraftCryptoConfig`；它们不等于公开上游或任意同名 PyPI 包均支持。先核对模块路径、签名与平台依赖，来源见 [compatibility-sources.md](compatibility-sources.md)。其他库/版本使用适配的工具；缺依赖时给出明确错误，不自动覆盖安装、替换编辑器组件或悄悄降级。
- Windows 常见 User Data 在 `LOCALAPPDATA/JianyingPro/User Data`，根索引在其 `Projects/com.lveditor.draft/root_meta_info.json`，但媒体草稿目录可能已自定义。读取当前配置/索引确认实际路径。软件安装目录亦需现场发现。
- 默认本机注册需要确认实际根索引；用户明确只导出时不访问或修改它。依赖不可用不应阻止已能完成的素材/源工程打包；对无法完成的原生构建或注册明确标注，不把便携 ZIP 生成视为本机已导入。

## 本机注册助手

明确调用本 skill 的默认交付包含本机注册，不再要求用户额外说“直接导入”；当次只导出覆盖优先。普通注册默认不做原生复检；`--allow-unreviewed` 保留为相同模式的兼容参数。用户明确要求检查已有完整原生证据时加 `--require-native-evidence`；真正的校准/测试稿才用 `--allow-unvalidated-test-draft`。三种模式互斥。不要为了正常导入强制把草稿伪装成测试稿，也不能因缺证据自动启动校准。

已完成原生验收且本次要求核验证据后，使用 `--require-native-evidence`：读取包内 `native-evidence.json`，或以 `--native-evidence` 指定包内其他 JSON。仅指定证据路径不会启动证据检查。证据绑定最终草稿、媒体、字体、画布、时长/帧率与实际剪映版本及 exe SHA-256。版本文件改变后证据失效，重新校准及审核仍需用户明确提出。

所有命令中的路径都是当前任务确认的参数，使用正确的 shell 引号。底层脚本省略 `--install` 时仅预检，不写剪映目录；这不是 Skill 默认注册的完整执行：

```text
python scripts/install_draft.py --package PACKAGE --user-data USER_DATA --draft-root DRAFT_ROOT --jy-install JY_INSTALL --name NEW_NAME
```

默认本机导入且未要求原生验收时，用具备兼容库的 Python 加 `--install` 执行。它仍执行安装前必要的结构与素材检查，保留动效/系统字体等未确认提示，不追加原生复检。同名拒绝覆盖；选择新的名称即可，无需因此让用户重复批准已经授权的新草稿创建。不要向脚本提供用户正在编辑的现有草稿名。

```text
python scripts/install_draft.py --package PACKAGE --user-data USER_DATA --draft-root DRAFT_ROOT --jy-install JY_INSTALL --name NEW_NAME --install --audit-dir AUDIT_DIR
```

助手会在写入前校验包、记录根索引和既有草稿，复制素材到新目录，重定向素材及嵌套字体路径，然后通过本地库保存与注册。不能仅复制目录就声称已注册；应确认唯一索引记录和媒体链接。

普通未复检注册成功返回 `registered_native_review_not_performed`，不强加 `[TEST]`；`exportStatus`、`registered/registrationStatus`、`nativeReviewStatus` 分开记录。`deliveryReady:false` 仍描述原生证据门禁，不能解释为没有导出或没有注册。正式证据模式存在未解决的动效风险时，在写入前停止；切换普通未复检模式必须符合用户的实际交付范围，不能偷偷改模式来宣称原生验收通过。

保存后、报告安装完成之前，助手重新核对新目标目录内清单所列全部媒体（含字体）的字节数与 SHA-256，并保存 `installed_media_verification.json`。缺失、越出目标目录或内容变化时，安装结果为未完成且 `deliveryReady:false`，保留新目录与审计，不回滚索引或覆盖用户文件。

校准必须先注册才能原生采样时，可以明确使用测试模式：

```text
python scripts/install_draft.py --package PACKAGE --user-data USER_DATA --draft-root DRAFT_ROOT --jy-install JY_INSTALL --name CALIBRATION_NAME --install --allow-unvalidated-test-draft
```

此参数只跳过安装助手的原生证据门，不跳过结构、路径、媒体或已有草稿保护检查。名称若无 `[TEST]` / `[CALIBRATION]` 前缀，助手强制加 `[TEST]`；结果及审计始终 `deliveryReady:false`，成功状态为 `test_only_installed_not_for_delivery`。如实说明该注册模式，不将其宣称为原生验收通过；工具的测试标签不撤销导出完成状态。仅在用户明确要求后采样审核、更新证据或另建正式草稿。

剪映运行中不自动关闭、重启或控制 UI。注册前发现根索引或既有草稿变化时，保留已完成的新目录和审计记录，停止注册并重新读取现状；不得用旧备份覆盖用户新状态。唯一可继续的自动扫描情形是：旧草稿、全部原条目及根字段完全未变，仅新增唯一指向本次目标目录的索引项，且 ID 匹配本次 `create_draft` 创建的 stub 或最终 payload、名称匹配目标。如果库创建时只复制了空 ID 模板，助手保存该初始快照；随后仅在当前自建目标的 sidecar 与唯一新增索引项拥有相同新 ID、名称/路径匹配、仍为零时长且无时间轴素材的空 stub、该 ID 未被旧草稿使用、已写入的目标 payload 未被更改时，接纳编辑器补写的身份。不得只凭索引里的陌生 ID 扩大允许列表。助手记录扫描审计后由库正常 `save()` 完成一致注册。其他并发变化仍停止。重试采用新名称/明确清理自己创建的暂存副本，不能无限重试。

源包在验证后变化时停止；目标目录、媒体及封面复制前检查路径包含关系和链接，拒绝 Windows 保留名称/越界路径，不覆盖目标已有文件。审计目录新建在包和真实草稿根之外。`load_template` 后、`save` 前再次核对索引及既有内容，不能只在最后检查已被旧快照覆盖的结果。

第三方库 `save()` 内部仍存在读改写并发窗口；前后哈希与临时文件替换不能提供真正的 compare-and-swap 事务。当前助手不能保证完全消除编辑器同时保存造成的丢更新，也不会因此关闭或重启软件。本机导入检查不等于编辑器已经成功显示。注册失败报告实际阶段及可确认的注册状态，保留新目标和审计，不自动回滚索引、删旧稿或无限重试。

提供双击入口时，用正确引用自身目录的 `.cmd` 调用 PowerShell，包含中文的 Windows PowerShell 5 脚本使用合适的 UTF-8 BOM。不要把通常会在编辑器里打开的 `.ps1` 本身当作可靠的双击执行入口。打包只包含助手及声明依赖，不把某台机器的运行时绝对路径当通用要求。

## 最终报告

默认简短交付草稿名、安装目录、便携 ZIP 位置、编辑说明及“导出完成；便携包已生成；本机已注册；复检未执行”，随后结束，不追问复检。每项只按实际结果填写；明确只导出时写“注册未执行（用户指定）”，失败则写具体阶段与保留产物，不能套用成功模板。实际注册但未查看剪映首页时，说明首页显示未作界面确认。另有明确要求并实际完成检查时，再报告对应范围及证据；证据契约通过仍不代表整集正常速度播放或完整导出通过。已知复杂文字映射差异与图形内部编辑边界写入随包说明，重大可见差异同时在交付消息中提示。
