# 剪映分层导出：插画、文字、底板独立，信息卡文字独立

把已完成的视频及源工程转成便于修改的剪映草稿。沿用当前项目内容与效果，按下述口播字幕定位默认值及用户明确覆盖调整导出，其余只改变剪映交付结构。适用于 HTML/SVG、Remotion、AE 或其他可抽取图层的源工程；具体渲染适配依项目实现。

## 默认导出并导入本机；人工提出后才复检

- 默认完成两项交付：生成分层草稿后注册为本机剪映的新草稿；同时生成便携 ZIP，包含草稿、必要素材、编辑说明和 `双击导入本机剪映.cmd`，供备份或换机导入。本机注册由助手完成，不要求用户再解压 ZIP、双击脚本。不主动追加效果研究、原生校准或验收。
- 用户明确“只导出”“不要导入”或“只要压缩包”时跳过本机注册；明确只导入已有包时沿用该包，不重做视频或额外重建交付。仅修改/讨论本 skill 不触发真实草稿导入。
- 复检必须由用户明确提出，例如“复检这份草稿”“检查原生排版”或“在剪映里验收”。仅调用本 skill、要求导出、说“继续”或历史上同意过另一轮检查，都不构成本次复检指令；也不每次导出后主动追问是否复检。
- 默认不追加独立全包复检、原生证据门禁、逐帧画面对照、面板隐藏/移动/缩放测试、音画试听或 ZIP CRC 复验，不操作剪映 UI，不创建校准测试稿。清单哈希、构建器参数/能力约束，以及注册前后必要的结构、路径、素材和索引检查属于导出/安装本身。已知不支持的效果不能继续写入并仅靠“未复检”免责；修复导出转换错误，不借此扩展成原生校准。
- 分别记录导出、便携包、本机注册与复检状态；正常完成时写“导出完成；便携包已生成；本机已注册；复检未执行”。注册成功仅表示新目录、索引和媒体链接已完成，不等于首页已通过界面确认、原生排版或播放通过。原生证据缺失不阻止普通导出/注册，不把正常草稿改成测试稿。若已有构建器捆绑复检，关闭该阶段后执行；无法关闭时保留已生成结果并说明阻塞，不自动检查。
- 注册缺依赖、路径无法确认或发现并发修改时，保留草稿包与便携 ZIP，报告具体失败阶段；不能只交 ZIP 就声称本机已导入，也不通过反复建稿、覆盖索引或重启剪映追求首页立即显示。只有用户明确要求检查首页或原生操作时才进一步执行。
- 用户提出复检时，只执行指定范围；定位缺陷、修复并在该范围内验证由当次修复要求决定，不把一个问题扩大成全项目审查。单独的导出请求不授权原生复检。未执行的项目记录 `not_performed`，不得写通过。维护本 skill 时可在隔离数据上运行助手单元测试，不把它称为用户草稿验收。

## 范围与输入

- 仅手动调用：用户明确写出 `$jianying-layered-export` 或要求使用“剪映草稿分层导出”skill 时才应用本流程。只说“导出剪映草稿”或“导入剪映”不自动触发本 skill。以下默认分层规则只作用于明确调用本 skill 的任务，不成为其他项目的默认导出规则。
- 用户明确调用本 skill 时，默认范围包含新草稿的本机注册与便携 ZIP 交付，无需再要求用户重复说“直接导入”；当次只导出等覆盖优先。不因仅制作视频或一般剪映请求而自动触发本 skill。
- 读取当前项目实际入口与已确认配置；有 `production_standard.json` 时按其指针和哈希加载。不得把此 skill 所源自项目的 SOP、风格、镜号或目录当作其他项目标准。
- 查清成片、源工程、时间轴、可编辑文字、原始音轨和素材所在位置。继承原画幅、帧率、时长、字幕模式、人物动作、配色及字体，不固定轨道数、卡片数或音效数量。
- 仅有压平 MP4 或已烧录文字/底板的插画图片时，无法直接恢复原始文字/图形图层。先检查已有工程与无字素材；缺失时说明可交付边界并请求必要源工程，不把整张图片或一段完整 MP4 声称为完整分层。
- 原成片、制作规则、SOP、原始源码与用户编辑过的草稿保持原样。新建项目内导出修订目录和独立草稿；转换代码放该目录。旧草稿的手动修改需要另行迁移，不能暗示已经保留在新稿中。

## 默认分层规则

| 内容 | 草稿中的结构 |
|---|---|
| 动画层插画 | 按当前项目的画面及动作规则保留每幅插画/镜头，用独立图片或视频片段承载；移除另行导出的文字及其底纹/底框，保留干净插画 |
| 动画层文字 | 标题、说明、标签等按逻辑文本块及连续出现时段分别建立原生可编辑文字片段，保留原位置、样式、时序及源工程允许的动效 |
| 动画层文字底纹/底框 | 为每个独立文字底板建立单独的透明图形片段，与插画及文字分开；可单独移动、缩放、替换。源中分别可调的底纹与边框继续分开；本来同属一个底板的填充、纹理、描边可作为一个单元 |
| 信息卡文字 | 标题、正文、数字、标签等，每个逻辑文本块的连续出现时段对应独立原生可编辑文字片段；不按帧拆碎，必要的再次出现按下文关联 |
| 信息卡其余元素 | 每张卡的背景、所有框体、图标、插图、线条、箭头、跨框关系及非文字动效合成一个连续画面片段；静态可用图片，动态用视频，保留完整过程、中间状态、配色和时序 |
| 口播字幕及其底板 | 默认共同固定在画面底部中央，采用稳定的字幕基线；只有用户明确要求时才横移或改变定位 |
| 配音、音效、配乐 | 按已有声音来源保留独立片段/声部，时间不重叠时复用轨道，避免重复混音或重复应用增益 |

“其他元素一层”以每张信息卡为单位，不把全片所有卡片合成一个长视频；不同卡片可复用同一视频轨道。原有大框、框内图形、背景和跨框公共层均合入该卡的非文字层。口播字幕及其底板、独立声音不烘焙进信息卡。单卡内部图形可整层移动、缩放或替换，内部元素调整需回到源工程重渲。

“每段文字单独”指独立可编辑片段，不是全片每句话都永久占一条轨道。轨道按并发占用和前后遮挡复用；单卡内同时出现的独立文字不能相互覆盖。

动画层的三个编辑单元按实际内容建立：无字无底板的插画、每个原生文字块、每个文字底板。有文字而无底板时只建前两类，没有的内容不造层。文字与其底板分别保留片段和素材，不放进会阻碍独立编辑的复合片段或自动编组。动画层标题/标注不因位于底部就改成口播字幕，也不套信息卡“其余元素合成一层”的规则。画面本身的纸张纹理、环境背景和道具外形属于插画，按对象用途识别文字底板。

底纹/底框默认以独立透明 PNG 或保留原过程的透明视频交付；素材内部的纹理、颜色、路径不会因此自动成为原生矢量控件。需要直接调整这些内部属性时，应使用实际支持的独立原生形状，或回源工程重渲对应底板并替换。如原始插画已将字和底板画在像素中，先从可拆源工程取得干净底图或制作独立导出副本；不能只在旧字上叠新字、复制整幅图片到多轨或按矩形裁图冒充分层。详见 [动画层的插画、文字与底板拆分](references/adapter-notes.md#动画层插画文字与底板独立)。

口播字幕定位规则按内容用途识别，只作用于跟随配音逐句显示的字幕及其底板。默认取消左右滑动、由左侧移到中央及句间换位；源工程已有横移不等于用户要求保留。信息卡标题、说明、标签及图形的正常动效继续保留，不能把所有文字或底部元素一并固定。执行细节见 [口播字幕的固定定位](references/text-motion.md#口播字幕的固定定位)。此默认值用于以后调用本 Skill 的导出，不追溯修改旧草稿、成片或项目 SOP。

原生文字片段按实际出现时段设置，不为了保持“一段”而铺满整个镜头再用缩放到零隐藏。跨不连续出现区间时，优先使用已支持的原生可见性机制；必须拆段时按语义出现区间拆分并在索引中关联，不能逐帧碎片化，也不能声称多个独立片段改一次就全更新。

片段标明 `镜号｜卡名｜非文字合成` 或 `镜号｜卡名｜文字内容`，编辑索引关联到源对象。默认不自动编组；整卡移动时可按索引多选非文字片段和文字片段。只有用户明确要求按大框或对象继续拆分时，才使用 [按大框拆分的可选模式](references/adapter-notes.md#可选模式按大框拆分)，不能从旧导出器继承该模式为默认值。

合层时须先移除已转为原生文字的栅格字形，避免重复字。保留文字自身的正常动效及其与非文字对象的同步。若原场景有图形遮挡文字或交错层级，优先用当前已支持的原生裁剪、遮罩或显隐保留关系；不能把本应被遮挡的字强行置顶。单层非文字与可编辑文字无法同时保真时，说明具体冲突并按用户已定优先级处理，必要时询问该项取舍；不得默默多拆非文字层、压平文字或改变效果。

文字里的关键词、标题和说明默认保持原生文字。对透视、剪切、路径文字或复杂遮罩，先核实当前原生能力；不能默默去掉变换或把字烘焙后仍称可改字。可编辑性与效果保真无法同时实现时，说明具体对象和可用方案，按用户已有优先级处理；没有足够依据时才询问该取舍。已有演示录屏里的软件界面文字属于录屏内容，不伪装成可编辑文本。

## 执行路径

1. **确定导出边界**：记录基准文件哈希、时间轴、声音处理和允许变化范围。识别插画中可拆的文字/底板、干净底图及已烧录内容。使用当前输入，自行解决可逆实现细节，不增加逐卡确认关卡。
2. **建立对象归属**：为每幅插画/镜头、每个逻辑文本块、文字底板及信息卡建立稳定 ID。动画层分别归属插画、文字和底板；信息卡仍将该卡所有非文字对象归入同一个导出编辑单元，单独记录文字映射。保留源对象的语义归属供重渲追溯，不能按画面左右硬裁。未归属或多重归属先修复，不默默漏掉。
3. **抽层并建草稿**：沿用当前项目适配器，先使其符合本次分层方式，再按 [适配技术说明](references/adapter-notes.md) 和 [文字动效映射](references/text-motion.md) 补齐实现。先区分官方产品说明、开源上游与本机分支，参考 [已核对的来源及边界](references/compatibility-sources.md)。枚举存在、JSON 可写、构建成功均不能证明编辑器支持该效果。禁止把文字透明度转换为人为的零缩放；无文字 Alpha 能力证据时不直接套用视频 Alpha 关键帧。使用适用的已有字号/位置映射，不把经验倍率当通用公式。去掉改为原生文字的重复栅格文字；将每卡其他元素合成一层，保持动画连续性与源遮挡顺序。已知错误必须解决，未确认兼容性和效果取舍分别说明。
4. **注册与便携交付**：按 [包结构契约](references/package-schema.md) 生成草稿包，按 [交付说明](references/delivery.md) 用现有安装助手新建并注册本机草稿，同时生成带双击导入入口的 ZIP；明确只导出时跳过注册。注册做必要结构/素材/索引检查，不执行原生复检；缺依赖或注册失败如实记录并保留已完成交付。给出草稿名、安装目录、ZIP 路径和实际状态后结束。合层只调整交付结构，不改变视频制作规则。

## 复检与证据（仅在用户明确提出后）

- 按用户指定范围选择以下项目，不自动全部执行。结构复检用 `validate_package.py --structure-only`，同时报告动效风险提示。完整原生证据检查用 `--require-native-evidence` 并读取 [原生证据契约](references/native-evidence.md)。旧 `--allow-unvalidated-test-draft` 仅保留兼容测试工作流，不再用测试标记替代普通的“未复检”状态。
- 声称原生校准及最终排版通过，必须具有绑定最终草稿、字体、全部媒体、画布与剪映版本的实际证据。原生证据来自剪映画面或剪映实际导出的采样帧；完整排版验收覆盖全部原生文字，局部复检仅声明实际覆盖范围。SVG/PIL 重画不能代替原生证据。证据采集、正常速度播放与完整导出分别授权和记录，不互相替代。
- 对每张卡选择运动中、到达后及遮挡变化的代表帧，解码最终交付 PNG/MOV 并重组，与源画面对照。检查 alpha、黑边、裁切、字体、时间与图层顺序；编码前截图不能替代编码后检查。
- 默认模式复检每卡只有一个非文字合成片段，文字为独立原生片段，移除或改字后没有残留栅格字；合成素材内包含该卡全部非文字过程。合层后各大框随素材整体移动属于预期，不再以“相邻框不联动”为默认验收条件。
- 仅在用户选择按大框拆分模式且要求该项复检时，隐藏、移动、缩放单框图形，检查相邻框不变及跨框连接独立。使用最终草稿的位置、缩放、层级和最终资产做检查。
- 原生文字可独立修改；不同文字及不同卡片不会因共用可变 material 或分组而串改。一个逻辑文本因再次出现而拆为多个片段时，如实说明各片段的编辑关系。
- 用户要求动画层分层复检时，检查插画、文字和文字底板是否为独立片段；隐藏或修改文字后，插画和底板内没有重复旧字；单独移动/替换底板不会带动插画或文字。保留源遮挡与时序，检查范围以当次要求为准。
- 核对声音源、偏移、时长、已烘焙处理与片段音量，不同时叠加已混合母轨和其拆分声部。针对实际保留的音轨检查同步与增益。
- 报告绑定草稿、素材清单和检查依赖的哈希。相关输出改变后标记旧证据失效，仅在用户提出复检后重跑对应项目；区分结构通过、编码后画面通过、剪映原生播放/导出通过，不能互相替代。

## 交付要点

提供可用草稿、所需媒体与字体、按动画镜头/插画及信息卡的编辑索引、可重渲源工程或其已交付位置，以及实际完成的核验。索引区分动画插画、动画文字、文字底板、信息卡非文字合成及口播字幕。说明文字可原生编辑；动画文字底板可单独调整/替换，其内部纹理和路径的编辑能力按实际素材记录；每卡其余元素是一层可移动/替换的合成素材，内部图标、框体和路径需通过源工程重渲。

给出新草稿名、安装目录、便携 ZIP 位置及注册状态，本机注册成功后不把脚本或 ZIP 当作唯一成果。便携包需完整解压后再双击导入；已注册的当前电脑无需再执行一遍。保留旧草稿并说明是否迁入用户手动修改。用户自行寻找草稿时，不操作剪映界面、不重启编辑器，也不为首页是否立即显示反复检查。
