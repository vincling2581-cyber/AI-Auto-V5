# 原生文字的时间、显隐与动效

抽取或构建原生文字时读取。这里修正的是转换规则，不要求每次导出额外操作剪映。能力来源及版本范围见 [compatibility-sources.md](compatibility-sources.md)。

## 口播字幕的固定定位

用户未明确要求特殊定位或横移动效时，跟随配音逐句显示的口播字幕及其底板默认固定在画面底部中央。先用字幕来源、角色标记和配音对应关系识别它们，例如 `subtype:subtitle` 及对应底板归属；不能仅凭 `role:text`、文字内容或位于画面下方判定。信息卡中的标题、说明、标签、数字及图形保持原有正常动效。

- 字幕与底板同步采用画布水平中心；在本适配器的中心坐标约定中为 `x=W/2`、剪映 `transform.x=0`。根据当前画幅和项目字幕区确定稳定的底部基线及安全边距，不写死某集的像素高度。文字与底板保留原有垂直对齐间距，无需强行使用同一个 Y 中心。
- 在源状态转为剪映参数时应用固定定位，去掉字幕及底板的水平位移轨迹、滑入滑出、从左侧到中央的交接和句间换位；避免父级变换或原生动画重新引入移动。纵向保持已确定的底部基线。保留文字内容、配音时序、样式、底板外观，以及与固定定位兼容的显隐效果。
- 即使字幕透明度全程为 1，也必须处理定位；不能因为没有淡入淡出就跳过已有的位置关键帧。底板若把位移烘焙进素材，应从源重做这一底板的固定版本，不能只清除外部关键帧后宣称已经固定。
- 源工程或旧草稿本来有横移，不构成保留它的授权。用户明确要求某句、某时段或某集使用特殊字幕动效时，只在该范围覆盖默认值，记录对象、时间范围和用户要求，不扩大到其他集。

这是导出时的定位规则，不自动增加原生校准、播放或其他复检，也不修改既有交付文件。

## 先确定效果是否可表达

分别记录文字的位置、旋转、大小、透明度、颜色、剪切/透视和局部遮罩。通用关键帧 API 接受一个枚举，不代表每种媒体都会执行它。公开 pyJianYingDraft 在本次核对版本仅承诺文字的位置及大小相关关键帧，`KFTypeAlpha` 注明用于视频；不要从视频淡入示例推断文字支持。

文字 Alpha 只有在目标剪映版本、库/适配器版本和具体写法具有相应原生证据时才标为支持。旧项目静态字号校准、最终截图或素材合成通过都不能代替动态透明度证据。没有该证据时，优先复用已适用的剪映原生文字入场/出场动画；核对当前库的动画枚举、默认时长、`duration` 参数和资源依赖，不把中文显示名当跨版本固定标识。

公开上游文字入场动画从片段头开始，出场动画在片段尾结束。仅设置 `add_animation(duration=...)` 不会替你把一个从 0 秒开始的文字延迟到第 4 秒出现。片段起止和动画时长必须来自源时间轴；复杂内部闪现、长暂停或任意透明度曲线不能假装一次原生入场就等效。

## 禁止用可见性改变几何

- 不做 `scale = 0 if alpha == 0 else source_scale`；它把显隐变成几何变化，在不执行文字 Alpha 的运行时会突然缩没或弹出。
- 将零改成 `0.001` 也不解决原理问题。不要把这个值当通用兼容修复。
- 源动画本来有意缩放到零时，保留它并标明来源；禁止的是为了隐藏而额外引入缩放，不是禁止合法缩放动画。
- 文字未出现前及最后消失后的区间不必占据时间轴；使用实际有效区间，并让关键帧时间相对于新的片段起点。
- 中间隐藏后再次出现：有经确认的可见性方法时可保留一段；否则按实际出现区间拆成少量片段，使用共同逻辑键和明确的编辑索引。不得复制成逐帧文字，或让用户以为改一个片段会自动修改全部副本。
- 若源中存在渐变透明度而当前能力不能表达，必须标为尚需映射。按已有用户优先级选择适用的原生动画或明确的素材化方案；没有支持依据时，不悄悄删除渐变，也不恢复零缩放权宜办法。

## 可复用的纯函数

`scripts/text_motion.py` 提供 `plan_text_visibility(samples, fps=..., text_key=..., alpha_keyframes_verified=False)`。它接收按源帧率求值的连续帧，输出实际透明度活动区间、相对时间、保留原几何的变换样本和仍待处理的透明度要求。它不创建草稿、不调用剪映，也不证明原生效果。

输入应覆盖该逻辑文字完整的源时间范围。只输入第 4–5 秒的采样，只能得到这一窗口内的计划，不能据此推断文字在后续整段中的结束时刻。

```python
from text_motion import plan_text_visibility

plan = plan_text_visibility(source_states, fps=source_fps, text_key=logical_id)
if plan['status'] == 'needs_mapping':
    # 根据 requirements 选择当前已支持且时序相符的原生文字动画。
    # 未完成映射前不能把 plan 当作效果已完整保留的输出。
    ...
```

适配器可直接调用此函数或实现同等约束。写包时用输出的 `segmentKey` 作为该出现片段唯一的 `manifest.segments[].textKey`，用原始 `textKey` 记录 `logicalTextKey` 及编辑索引关联；每段仍有独立原生 material。`alpha_keyframes_verified=True` 只用于已有对应证据的情况，不能为了获得 `ready` 而打开。函数不会自动赋予能力，也不会因为某张截图正确就开启文字 Alpha。`opacityActiveSpans` 根据源透明度计算，并不证明文字未被其他图层遮挡或位于画幅内。

## 时间与关键帧

- `T(f)=round(f*1_000_000/fps)`；片段 `[a,b)` 的时长是 `T(b)-T(a)`，关键帧偏移是 `T(f)-T(a)`。不累加四舍五入后的单帧长度。
- 时间必须有序、唯一且处于片段内，数值有限。缺失源帧不能直接解释为不可见，应先按源动画求值；同一时点重复写入不同状态属于转换错误。
- `uniform_scale` 与独立的 `scale_x/scale_y` 模式不能混用；锁定实际库语义。上游等比缩放映射到 `KFTypeScaleX` 并设置等比开关本身是正常行为，不能看到一个 X 通道就断言缺少 Y。
- 不均匀缩放时保留两个轴。剪切、透视矩阵不能仅靠“旋转+双轴缩放”精确还原；文字完全不可见阶段的不可表达矩阵与真正可见时的差异要分开记录。
- 压缩关键帧必须保持所采用插值下的曲线，不能仅按值去重或任意删掉隐藏前后的边界。曲线存在不等于剪映会按它执行。

## 声明与复检

可在段清单中记录 `motionIntent`，例如 `{"visibilityMethod":"segment_ranges","scalePurpose":"source_animation"}`。若明确声明 `visibilityMethod` 为 `zero_scale`、`scale_zero` 或 `alpha_to_scale` 并出现零缩放切换，结构复检会优先将其作为转换错误。声明 `scalePurpose:"source_animation"` 且显隐使用 `segment_ranges`、`native_animation` 或 `native_alpha` 时，零缩放发现记入信息级 `motionInfo`，仅表示声明来自源动画，不单独阻断交付，也不证明原生效果。实际写入文字 Alpha 仍会独立提示兼容性未确认。其余未知意图的零缩放及未经确认的文字 Alpha 进入风险提示；不能修改声明来掩盖真实的转换缺陷。

用户要求检查跳字时，只定位对应文字及时间窗口，先对比源和草稿的起止、透明度、缩放及关键帧。真正确认运行时效果需要剪映预览或其导出；静态数值分析只能证明转换差异。不要把结构通过写成“不会跳字”，也不要因此自动重做全片校准。
